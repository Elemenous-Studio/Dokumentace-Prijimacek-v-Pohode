## Project memory (Obsidian vault)

`obsidian/` is this project's shared memory (plans, decisions, tasks, runbooks, session log), and **every folder in it has a `CLAUDE.md`** with its own rules. Read `obsidian/CLAUDE.md` first, then `obsidian/Prijimacky Docs Home.md`, `Prijimacky Docs Tasks.md`, `Prijimacky Docs Open questions.md` and the newest note in `obsidian/Log/`.

After work: update `Prijimacky Docs Tasks.md`, add decisions to `Prijimacky Docs Decisions.md` (dated, with the reason), and write `obsidian/Log/YYYY-MM-DD Prijimacky Docs.md`. Commit the vault with the code it describes. No secrets or personal data in the vault.
