# Plans/ — plans and specs

Part of the Prijimacky Docs vault. Start at `../CLAUDE.md` if you haven't.

**What goes here:** forward-looking work — a feature plan, a migration, an architecture change. One note per plan, `type: plan`, named `Prijimacky Docs <topic> plan`.

**Shape:** Goal → Decisions taken (link to `Prijimacky Docs Decisions`) → Steps/phases with GitHub issue numbers → Open questions → Status line at the top (`Status: draft | approved | in progress | done`).

**When a plan is done:** set `Status: done`, keep the note (it's history), and make sure `Prijimacky Docs System overview` describes the new reality.

If the full spec is long and lives in the repo (`docs/`), the note here is a 1-page summary that links to it.

General rules: frontmatter on every note, bump `updated`, link the note from `Prijimacky Docs Home` (or the relevant parent note), no secrets or personal data.
