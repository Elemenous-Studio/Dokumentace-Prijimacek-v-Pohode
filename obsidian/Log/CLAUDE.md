# Log/ — session log

Part of the Prijimacky Docs vault. Start at `../CLAUDE.md` if you haven't.

**What goes here:** one note per work session (or per day), named `YYYY-MM-DD Prijimacky Docs.md` (the prefix keeps names unique across the main vault). `type: log`.

**Shape:** `# YYYY-MM-DD — <one-line summary>` → **Done** (with PR/issue numbers) → **Not done / lost** → **Next**. Keep it short; decisions go to `Prijimacky Docs Decisions`, tasks to `Prijimacky Docs Tasks` — the log links to them.

Add the new log note to the *Log* list in `Prijimacky Docs Home` (newest first). Never rewrite old logs except to fix a broken link.

General rules: frontmatter on every note, bump `updated`, link the note from `Prijimacky Docs Home` (or the relevant parent note), no secrets or personal data.
