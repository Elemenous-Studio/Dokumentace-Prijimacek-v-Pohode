# Reference/ — stable reference

Part of the Prijimacky Docs vault. Start at `../CLAUDE.md` if you haven't.

**What goes here:** facts that don't change often and that you'd otherwise rediscover — domain rules, external service notes, API conventions, data model, glossary, environment variables (names only). `type: reference`.

**Not here:** plans (→ `Plans/`), procedures (→ `Runbooks/`), session history (→ `Log/`).

When a fact turns out to be wrong, fix the note in place and mention the fix in the session log.

General rules: frontmatter on every note, bump `updated`, link the note from `Prijimacky Docs Home` (or the relevant parent note), no secrets or personal data.
